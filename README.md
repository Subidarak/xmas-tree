# 🎄 圣诞树 · 单文件互动网页

一棵 3D 粒子圣诞树、点开礼盒照片飞出的祝福页。**整个页面就是一个 HTML 文件**：零依赖、零构建、断网也能开，发微信、挂 GitHub Pages 都行。

## 在线演示

**https://subidarak.github.io/xmas-tree/**

打开就能玩：点星星 → 点礼盒 → 拖张照片进页面，照片会绕树排成一圈。

## 交互

| 动作 | 效果 |
|---|---|
| 点星星 | 树亮起，飘雪 |
| 点礼盒 | 盖子打开，照片飞出、绕树成环 |
| 拖动 | 旋转树 |
| 点照片 | 看大图（Esc 或点任意处关闭） |
| 拖图片进页面 / 点「＋ 挂照片」 | 加一张照片，最多 12 张 |
| 「重播开场」 | 从头再放一次开盒动画 |
| 「清空」 | 清掉所有照片 |
| 「打包网页」 | 导出一份可分享的单文件 `index.html` |

「打包网页」会把每张照片压到长边 1280px 以内、以 JPEG 内嵌进 HTML，导出的那份是**分享模式**：工具栏隐藏，对方打开就是一棵挂好照片的树。一个文件就是全部内容，8 张照片约 1MB 出头。

## 技术说明

- 纯 Canvas 2D 手写渲染，没有框架、没有打包工具、没有 CDN
- 照片只活在浏览器内存里，编辑时不上传任何服务器；只有「打包网页」时才写进 HTML
- 背景音乐用 WebAudio 现场合成，不加载任何音频文件
- 字体只用系统字体（华文中宋 / 宋体 / Georgia 回退），不联网取字
- 竖屏手机与桌面共用一套布局，按视口比例算树的几何

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 可交互演示（编辑模式，可加照片、可导出） |
| `cloud/` | 云端多人版：让朋友自己挂祝福（Node + Caddy + Docker Compose） |
| `docs/` | 设计记录：树容量方案、多树滑动切换方案 |

## 本地打开

双击 `index.html`，或者：

```bash
python -m http.server 8000   # 然后访问 http://localhost:8000
```

## 云端多人版

`cloud/` 里是「朋友扫码进来、自己选照片写名字挂到树上」的完整实现：Caddy 负责 HTTPS 与静态托管，Node 只跑两个接口（列表 / 投稿），数据和照片落在宿主机目录。部署方式见 [cloud/README.md](cloud/README.md)。需要自己的域名和一台小服务器。

## 隐私

本仓库不含任何真实照片、祝福数据、域名或服务器信息，示例里的域名一律是 `your-domain.example.com`。
